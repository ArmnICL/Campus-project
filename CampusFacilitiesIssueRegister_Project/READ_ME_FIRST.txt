CAMPUS FACILITIES ISSUE REGISTER - VISUAL STUDIO DEVELOPMENT PROJECT


HOW TO OPEN
1. Install Visual Studio 2026 Community with .NET desktop development,
   Data storage and processing, .NET Framework 4.8 development tools, and
   SQL Server Express LocalDB (MSSQLLocalDB instance).
2. Extract this ZIP to a writable folder such as Documents.
3. Double-click CampusFacilitiesIssueRegister.sln.
4. Allow Visual Studio to retarget or install .NET Framework 4.8 if prompted.
5. Build > Build Solution. Fix any environment-specific issues shown.
6. Press F5. The program attempts to create a real SQL Server LocalDB database
   and one table on the first run (requires LocalDB available and running).
7. Test Add, View, Update, Delete, Search, validation and persistence after restart.
8. Check that CampusFacilitiesIssueRegister/Database/ contains .mdf and .ldf.
   Close Visual Studio/application before copying these database files into final ZIP.
